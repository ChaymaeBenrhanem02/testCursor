# Partie 1 — Landing page

Page d'accueil simple en HTML/CSS vanilla.

## Lancer en local

```bash
python -m http.server 8080
```

Ouvrir http://localhost:8080

## Modifier

- `index.html` — contenu
- `styles.css` — apparence

Demandez à Cursor : *« Change le titre en ... »* ou *« Ajoute une section témoignages »*

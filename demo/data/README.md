## Colonnes

| Colonne | Description |
|---------|-------------|
| nom | Nom du contact |
| email | Adresse email |
| entreprise | Société |
| secteur | Secteur d'activité |
| statut | nouveau, contacté, qualifié, gagné, perdu |
| date_contact | Date du dernier contact (AAAA-MM-JJ) |
| montant_estime | Valeur estimée en euros |
